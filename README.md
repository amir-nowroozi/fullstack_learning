# fullstack_learning
 
این کار برای کمک به من هست برای یادگیری طراحی سایت و فریلنسری
از اونجایی که به این کار علاقه زیادی دارم میخوام که درآمد زاییم رو شروع کنم

فایل های مربوط به فرات رو در پوشه my_shop و فایل های مربوط به بک اند رو در پوشه my_shop_backend قرار دادم 

# اجرای پروژه

## ترمینال ۱ — بک‌اند
cd my_shop_backend
npm run dev

## ترمینال ۲ — فرانت
cd my_shop
npm run dev
